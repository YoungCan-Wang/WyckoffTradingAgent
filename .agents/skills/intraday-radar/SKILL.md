# 全市场盘中高频雷达与威科夫实战执行规程 (Intraday Radar Skill)

本技能定义了**盘前与午间全球视角反身性扫描、全市场 7,807 标的（5,578 只 A 股 + 1,677 只 ETF + 598 只指数）每 5 分钟差分扫描、威科夫 `L2+L3 地量蓄势 / 吸筹` 点火捕捉、以及飞书四级加急通知（普通/App/短信/电话）**标准作业程序（SOP）。

---

## 一、 盘前与午间“全球视角（中英双语）”四维扫描与反身性规程（08:35 & 12:50）

1. **强制执行【中英双语全球视角搜索】**：
   * A 股核心行业（半导体、果链消费电子、海外算力光模块、新能源出海、大宗商品）受全球宏观政策、美联储/美债利率、汇率（USD/CNH）与跨国供应链驱动。
   * **四维必查清单（每次扫描同时发起中文 + 英文检索）**：
     1. **🌍 全球政经与地缘日历（英文必搜）**：美国大选/中期选举计票、美国国会涉华/关税/芯片法案动态、美联储（FOMC）表态、10年期美债收益率与美元指数（DXY）、离岸人民币汇率（USD/CNH）；
     2. **🌐 隔夜与亚太跨市场映射（英文+行情必查）**：费城半导体指数（SOX）、纳指100、中概金龙指数（KWEB）、美股盘后科技巨头财报（北京时间 `04:00~06:00`），以及北京时间 `08:00` 开盘的日韩股市（东京电子、SK海力士、三星电子）；
     3. **🏛️ 国内部委宏观政策（中文必搜）**：央行、证监会、金管局、发改委最新政策细则；
     4. **💰 早间上市公司真金白银公告（中文必搜）**：7:30~8:30 大额回购、增持、定增落地或业绩预告。
2. **⏰ 12:50 午间休市“全球突发与跨市场异动”扫描（覆盖 11:30~13:00 盲区）**：
   * 北京时间 `11:30~13:00` A 股休市期间，港股（`11:30~12:00`）、离岸人民币（USD/CNH）、美股夜盘期货、A50 期指仍在交易定价。
   * 每日 **`12:50`** 执行一次中英双语全球突发新闻与跨市场异动扫描；若午间出现重大国际宏观变化或汇率异动，在 `12:55` 前推送飞书预警。
3. **RPS 高低位反身性校验（防止高位接盘“利好出尽”）**：
   * 对政策或宏观事件受益板块，读取最新 `review_trace_*.json.gz`（按 A 股交易日计算，距离当日超过 3 个交易日自动告警忽略，兼容国庆/春节长假后首日）中该板块的 20 日 `RPS(fast)` 分布：
   * **高位兑现警告**：若板块核心股平均 `RPS > 80`，在盘前卡片标注 **“⚠️ 高位利好兑现风险，切勿早盘盲目追高”**；
   * **低位弹簧挖掘**：重点检索同受催化、处于超跌低位（`RPS < 35`）且同时命中威科夫 **`l2_eligible = True` 与 `l3_eligible = True`（或 `stage = 候选池已捕获`）** 的 `地量蓄势 / 吸筹` 标的。

## 二、 09:35 盘前预判强制证伪机制（向全市场 1,677 只 ETF 认错）

1. **09:35 强制校验**：
   * 运行 [intraday_radar.py](./scripts/intraday_radar.py) 拉取 `universes=["CN_Equity_A", "CN_ETF", "CN_Index"]`；
   * 检查全市场成交额 `>= 0.5亿`（`5,000万`）的 ETF 涨幅榜前 5 名；
   * **证伪切换原则**：若盘前看好的板块未进入 09:35 全市场 ETF 涨幅前 5 名，放弃盘前主观预设，切换至当日领涨 ETF 对应行业观察威科夫 `L2+L3` 标的。

## 三、 盘中每 5 分钟全市场高频差分雷达（09:30 ~ 15:00）

通过 [intraday_radar.py](./scripts/intraday_radar.py) 在 A 股交易时段（北京时间交易日 `09:25~11:35`、`12:55~15:05`，基于 `utils.trading_clock.cn_today`）每 5 分钟拉取一次全市场 `7,807` 只标的快照，并与上一份有效快照计算差分（`Δpct_5m`、`Δamt_5m`、`Δred_5m`）。

* **首次扫描与中途重启防误报保护（`_is_fresh_baseline`）**：仅当上一份快照属于当日且间隔 `<= 900 秒`（15 分钟，或处于 `11:20~11:36` 至 `12:55~13:12` 的午休跨段桥接窗口）时才计算 5 分钟差分；当日首次启动或中途停机超 15 分钟后重启时，仅重置基准快照并将差分置为 `0`，防止把数小时或全天涨跌幅误报为 5 分钟异动。
* **指数与个股严格隔离**：仅对沪深京 A 股（`.SH` 的 `60/68` 开头、`.SZ` 的 `00/30` 开头、`.BJ`）统计涨跌家数与匹配 `l2_map`，排除 `000001.SH`、`000300.SH`、`399001.SZ` 等指数干扰。

1. **持仓股 5 分钟贴身监控（冷却期内绝不降级误报）**：
   * **🔴 L4 破位止损（无成交额门槛，防开盘跳空/一字跌停漏报）**：持仓股 `现价 <= 预设硬止损价` $\rightarrow$ 立即触发 `L4` 电话加急（按 `86400 秒` 全天冷却，每个交易日仅拨打一次电话，且冷却期内不向下穿透降级为 L3/L2）；
   * **🟠 L3 持仓急跌**：持仓股 5 分钟急跌 `Δpct_5m <= -2.0%` 且 `现价 < VWAP` $\rightarrow$ 触发 `L3` 短信加急；
   * **🟡 L2 做 T 高抛**：持仓股偏离 VWAP `vwap_dev > +3.0%` $\rightarrow$ 触发 `L2` 应用内加急。
2. **威科夫核心池信号与市场共振监控**：
   * **🔴 L4 满级起跳板突破**：
     * 命中与当日 `review_trace_YYYYMMDD.json.gz` 同日期的 `recommendation_tracking_YYYYMMDD.json` 的 `springboard_combo == "A+B+C"`（严格过滤旧日期推荐文件），或 `review_trace` 内的 `entry.entry_type == "launchpad"` / `"启动平台"`；
     * 全市场红盘率 `> 80%`，5 分钟涨速 `Δpct_5m >= +2.5%`，总涨幅 `+2.8% ~ +6.0%`，`0% <= vwap_dev <= 2.0%`，5 分钟新增成交额 `Δamt_5m >= 0.30亿`。
   * **🟠 L3 威科夫 `L2+L3 地量 / 吸筹` 5 分钟点火**：
     * 同时满足 `l2_eligible = True` 且 `l3_eligible = True`（或 `stage == "候选池已捕获"`，精选约 480 只核心池），且 `l2_channel` 含 `地量` 或 `吸筹`；
     * 5 分钟新增成交额 `Δamt_5m >= 0.30亿`（`3,000万`）且当日累计成交额 `>= 1.0亿`；
     * 5 分钟涨速 `Δpct_5m >= +1.8%`，当前总涨幅处于 **`+2.8% ~ +5.0%`** 区间，现价在 VWAP 上方且乖离率 `0% <= vwap_dev <= 2.0%`。
   * **🟡 L2 行业共振与市场情绪骤变（严格去重防轰炸）**：
     * 仅以下三类带 30 分钟冷却的事件会将卡片升级为 `L2` 应用内加急：① 持仓股偏离 VWAP `> +3.0%`；② 同一行业内同时有 `>= 3` 只 A 股出现 `Δpct_5m >= +2.5%` 且 `Δamt_5m >= 0.30亿`；③ 全市场红盘家数 5 分钟变化 `|Δred_5m| >= 400 家`。
     * 全市场 ETF 5 分钟异动榜（成交额 `>= 0.5亿` 且 `|Δpct_5m| >= 1.0%`）与单股急涨急跌榜仅作为卡片面板展示，不单独触发 `L2` 应用内加急，避免盘中每 5 分钟频繁轰炸。

## 四、 飞书四级加急通知矩阵（普通 / App / 短信 / 电话）

卡片发送与加急请求统一通过 `lark-cli --as bot` 以同一机器人身份调用，**仅当飞书卡片实际发送成功（返回有效 `message_id`）后才将冷却时间戳写入状态文件**（防止网络抖动发送失败却提前锁死冷却）；守护进程 `--daemon` 连续 3 次扫描异常时自动推送一条 `L1` 故障告警卡片：

| 等级 | 飞书通知方式 | 触发命令 | 严格触发阈值 |
| :--- | :--- | :--- | :--- |
| **🟢 L1** | **普通互动卡片** | `lark-cli im +messages-send --as bot --msg-type interactive` | 默认距上次 L1 发送 `>= 29 分钟`（`1740s`）发送一次常规汇总（不受分钟漂移影响）；传入 `--force-send` 时每次扫描均发送卡片。 |
| **🟡 L2** | **飞书应用内加急** | 追加 `lark-cli im messages urgent_app --as bot` | ① 持仓股偏离 VWAP `> +3.0%`；<br>② 同行业 `>= 3` 只个股 5 分钟急涨 `>= +2.5%`（`Δamt_5m >= 0.30亿`）；<br>③ 全市场红盘家数 5 分钟变化 `|Δred_5m| >= 400 家`。 |
| **🟠 L3** | **飞书短信加急** | 追加 `lark-cli im messages urgent_sms --as bot` | ① 威科夫 `L2+L3 地量 / 吸筹` 核心池标的触发 5 分钟点火（`Δpct_5m >= +1.8%`，总涨幅 `+2.8% ~ +5.0%`，`0% <= vwap_dev <= 2.0%`，`Δamt_5m >= 0.30亿` 且总成交 `>= 1.0亿`）；<br>② 持仓股 5 分钟急跌 `<= -2.0%` 且跌破 VWAP。 |
| **🔴 L4** | **飞书电话语音加急** | 追加 `lark-cli im messages urgent_phone --as bot` | ① 持仓股跌破硬止损价（`last <= stop`，无成交额限制）；<br>② `A+B+C` 起跳板 / `launchpad` 标的在全市场红盘率 `> 80%` 下触发 5 分钟放量突破（`Δpct_5m >= +2.5%`）。 |

## 五、 验钞纪律与盘面观察准则

1. **严禁拿单只 ETF 成交额冒充全市场量比**：
   * 汇报大盘放量/缩量时，必须使用 `000001.SH 上证指数成交额 + 399001.SZ 深证成指成交额` 与昨日全天两市总成交额对比。
2. **评估个股时同时报出核心验钞指标**：
   * 快照雷达报出：`现价 (涨跌幅)` | `分时均价 VWAP (乖离率%)` | `5分钟涨速与5分钟新增成交额` | `威科夫 L2/L3 通道与 RPS`（对单标的做日线复核时额外拉取 2 日 K 线核对今日 vs 昨日全天成交额比例）。
3. **禁止因情绪迎合而改变客观标准**：
   * 坚持分时均价线（VWAP）与量能确认，不在均线下方盲目接飞刀，也不在远离均线（`vwap_dev > 3%`）时高位追涨。
4. **超跌首阳次日（`T+1`）盘面观察参考（经验观察，非自动执行指令）**：
   * 经验观察表明，当指数在均线空头排列（`C < MA20 < MA50`）下出现单日大幅超跌反弹后，次日（`T+1`）早盘常出现获利盘换手分歧，不宜在早盘集合竞价大幅高开时盲目追高；
   * 盘中重点观察指数与领涨主线在分时均价线（VWAP）附近的承接力度：若单边放量跌破分时均线且持续走弱，需防范“一日游”回落风险；若缩量回踩均线企稳并放量转强，再结合盘中硬指标评估右侧机会。

## 六、 本地 `lark-cli` 调用说明与执行命令

脚本直接调用本机已登录的 `lark-cli`（通过 `lark-cli auth status` 动态获取当前登录用户的 `identities.user.openId`，并以 `--as bot` 发送互动卡片与加急通知），**无需在代码仓库或磁盘配置文件中存储任何个人 `open_id` 或持仓信息**。如需在单次运行中附带持仓监控，可通过命令行参数 `--holding <代码:成本:止损>` 传入：

```bash
# 单次运行全市场 7,807 标的差分扫描（自动通过本机 lark-cli 发送）：
.venv/bin/python .agents/skills/intraday-radar/scripts/intraday_radar.py --once

# 盘中每 5 分钟守护扫描（自动对齐时钟周期、异常自愈、非交易时段休眠）：
.venv/bin/python .agents/skills/intraday-radar/scripts/intraday_radar.py --daemon --interval 300
```

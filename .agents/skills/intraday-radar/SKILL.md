# 全市场盘中高频雷达与威科夫实战执行规程 (Intraday Radar Skill)

本技能定义了**盘前与午间全球视角反身性扫描、全市场 7,807 标的（5,578 只 A 股 + 1,677 只 ETF + 598 只指数）每 5 分钟差分扫描、威科夫 `L2 = 地量蓄势 / 吸筹` 倍量起爆捕捉、以及飞书四级加急通知（普通/App/短信/电话）**标准作业程序（SOP）。

---

## 一、 盘前与午间“全球视角（中英双语）”四维扫描与反身性规程（08:35 & 12:50）

1. **强制执行【中英双语全球视角搜索】**：
   * A 股核心行业（半导体、果链消费电子、海外算力光模块、新能源出海、大宗商品）受全球宏观政策、美联储/美债利率、汇率（USD/CNH）与跨国供应链驱动。
   * **四维必查清单（每次扫描同时发起中文 + 英文检索）**：
     1. **🌍 全球政经与地缘日历（英文必搜）**：美国大选/中期选举计票、美国国会涉华/关税/芯片法案动态、美联储（FOMC）表态、10年期美债收益率与美元指数（DXY）、离岸人民币汇率（USD/CNH）；
     2. **🌐 隔夜与亚太跨市场映射（英文+行情必查）**：费城半导体指数（SOX）、纳指100、中概金龙指数（KWEB）、美股盘后科技巨头财报（北京时间 `04:00~06:00`），以及北京时间 `08:00` 开盘的日韩股市（东京电子、SK海力士、三星电子）；
     3. **🏛️ 国内部委宏观政策（中文必搜）**：央行、证监会、金管局、发改委最新政策细则；
     4. **💰 早间上市公司真金白银公告（中文必搜）**：7:30~8:30 大额回购、增持、定增落地或业绩预告。
2. **⏰ 12:50 午间休市“全球突发与跨市场异动”扫描（覆盖 11:30~13:00 盲区）**：
   * 北京时间 `11:30~13:00` A 股休市期间，港股（`11:30~12:00`）、离岸人民币（USD/CNH）、美股夜盘期货、A50 期指仍在交易定价。
   * 每日 **`12:50`** 执行一次中英双语全球突发新闻与跨市场异动扫描；若午间出现重大国际宏观变化或汇率异动，在 `12:55` 前推送飞书预警。
3. **RPS 高低位反身性校验（防止高位接盘“利好出尽”）**：
   * 对政策或宏观事件受益板块，读取最新 `review_trace_*.json.gz` 中该板块的 20 日 `RPS(fast)` 分布：
   * **高位兑现警告**：若板块核心股平均 `RPS > 80`，在盘前卡片标注 **“⚠️ 高位利好兑现风险，切勿早盘盲目追高”**；
   * **低位弹簧挖掘**：重点检索同受催化、但处于超跌低位（`RPS < 35`）且命中威科夫 **`L2 = 地量蓄势 / 吸筹通道`** 的标的。
4. **盘前双轨备选池**：
   * **A 轨（高 RPS 趋势回踩池，`RPS >= 75`）**：处于 `MA50 > MA200` 主升通道或 `A+B+C` 起跳板、等待盘中回踩分时均价线（VWAP）确认的趋势股；
   * **B 轨（低 RPS `地量蓄势` 反转观察池，`RPS < 75`）**：命中 `l2_eligible = True` 且含 `地量蓄势 / 吸筹通道` 的标的（不使用 `RPS >= 75` 过滤低 RPS 地量蓄势股）。

1. **09:35 强制校验**：

   * **证伪切换原则**：若盘前看好的板块未进入 09:35 全市场 ETF 涨幅前 5 名，放弃盘前主观预设，切换至当日领涨 ETF 对应行业观察威科夫 `L2 = 地量蓄势 / 吸筹` 标的。

## 三、 盘中每 5 分钟全市场高频差分雷达（09:30 ~ 15:00）

通过 [intraday_radar.py](./scripts/intraday_radar.py) 在 A 股交易时段（北京时间交易日 `09:25~11:35`、`12:55~15:05`，基于 `utils.trading_clock.cn_today`）每 5 分钟拉取一次全市场 `7,807` 只标的快照，并与当日上一份快照计算差分（`Δpct_5m`、`Δamt_5m`、`Δred_5m`）。

* **首次扫描防误报保护**：当日首次运行（尚无当日历史快照）时，仅建立基准快照并汇报静态行情，`Δpct_5m`、`Δamt_5m` 与 `Δred_5m` 均置为 `0`，防止将全天涨跌幅误判为 5 分钟异动。
* **指数与个股严格隔离**：仅对沪深京 A 股（`.SH` 的 `60/68` 开头、`.SZ` 的 `00/30` 开头、`.BJ`）统计涨跌家数与匹配 `l2_map`，排除 `000001.SH`、`000300.SH`、`399001.SZ` 等指数干扰。

1. **全市场 1,677 只 ETF 异动监控**：
   * **板块点火**：成交额 `>= 0.5亿`（`5,000万`）的 ETF，5 分钟涨速 `Δpct_5m >= +1.0%` 且现价 `>= VWAP`；
   * **指数跳水**：成交额 `>= 0.5亿` 的 ETF，5 分钟跌速 `Δpct_5m <= -1.0%` 且现价 `< VWAP`。
2. **全市场 5,578 只 A 股急涨 / 急跌与威科夫信号监控**：
   * **🔥 L3 威科夫 `L2 = 地量蓄势 / 吸筹` 5 分钟倍量点火**：
     * 命中 `l2_eligible = True` 且通道含 `地量` 或 `吸筹`；
     * **量比条件**：5 分钟新增成交额 `Δamt_5m >= max(昨日全天成交额 × 12%, 0.25亿)`；
     * **价格条件**：5 分钟涨速 `Δpct_5m >= +1.8%`，当前总涨幅处于 **`+2.8% ~ +5.0%`** 区间，现价在 VWAP 上方且乖离率 `0% <= vwap_dev <= 2.0%`。
   * **🔴 L4 满级起跳板突破**：
     * 命中 `A+B+C` 起跳板（`is_springboard = True`），全市场红盘率 `> 80%`，5 分钟涨速 `Δpct_5m >= +2.5%`，总涨幅 `+2.8% ~ +6.0%`，`0% <= vwap_dev <= 2.0%`，且 `Δamt_5m >= max(昨日全天成交额 × 12%, 0.25亿)`。
   * **🟡 L2 行业共振与市场情绪骤变**：
     * 同一行业内同时有 `>= 3` 只 A 股出现 5 分钟涨速 `Δpct_5m >= +2.5%`、5 分钟新增成交额 `Δamt_5m >= 0.30亿`（`3,000万`）且站上 VWAP；
     * 全市场红盘家数 5 分钟变化 `|Δred_5m| >= 400 家`。
   * **🌊 持仓股监控**：
     * 持仓股偏离 VWAP `> +3.0%` $\rightarrow$ `L2` 做 T 高抛提醒；
     * 持仓股 5 分钟急跌 `<= -2.0%` 且跌破 VWAP $\rightarrow$ `L3` 急跌预警；
     * 持仓股成交额 `> 0.5亿` 且跌破预设硬止损价 $\rightarrow$ `L4` 破位止损预警。

## 五、 验钞纪律与盘面观察准则

1. **严禁拿单只 ETF 成交额冒充全市场量比**：
   * 汇报大盘放量/缩量时，必须使用 `000001.SH 上证指数成交额 + 399001.SZ 深证成指成交额` 与昨日全天两市总成交额对比。
2. **评估个股时同时报出“四大验钞数字”**：
   * `现价 (涨跌幅)` | `分时均价 VWAP (乖离率%)` | `今日已成交额 vs 昨日全天成交额` | `昨晚威科夫 L2 通道与 RPS`。
3. **禁止因情绪迎合而改变客观标准**：
   * 坚持分时均价线（VWAP）与量比确认，不在均线下方盲目接飞刀，也不在远离均线（`vwap_dev > 3%`）时高位追涨。
4. **超跌首阳次日（`T+1`）盘面观察参考（经验观察，非自动执行指令）**：
   * 经验观察表明，当指数在均线空头排列（`C < MA20 < MA50`）下出现单日大幅超跌反弹后，次日（`T+1`）早盘常出现获利盘换手分歧，不宜在早盘集合竞价大幅高开时盲目追高；
   * 盘中重点观察指数与领涨主线在分时均价线（VWAP）附近的承接力度：若单边放量跌破分时均线且持续走弱，需防范“一日游”回落风险；若缩量回踩均线企稳并放量转强，再结合盘中硬指标评估右侧机会。

## 六、 本地私有配置与执行命令

个人飞书 `open_id`、持仓成本/止损与本地 trace 目录请配置在仓库外的 `~/.wyckoff/intraday_radar_config.json`（权限 `0600`）或通过环境变量 `FEISHU_USER_OPEN_ID` 传入，**严禁将个人信息硬编码提交至代码仓库**：

```json
{
  "feishu_user_open_id": "ou_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "holdings": {
    "600000.SH": {"cost": 10.0, "stop": 9.5}
  },
  "trace_dirs": ["~/.wyckoff/traces", "/tmp", "data"]
}
```

```bash
# 单次运行全市场 7,807 标的差分扫描：
.venv/bin/python .agents/skills/intraday-radar/scripts/intraday_radar.py --once

# 盘中每 5 分钟守护扫描（自动在交易时段运行，非交易时段休眠）：
.venv/bin/python .agents/skills/intraday-radar/scripts/intraday_radar.py --daemon --interval 300
```

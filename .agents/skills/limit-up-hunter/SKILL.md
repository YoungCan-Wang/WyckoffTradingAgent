# A股游资抓板抓妖与连板梯队盘中观察规程 (Limit-Up Hunter Skill)

本技能专为 **A股超短连板接力、龙头晋级（`1进2` / `2进3` / `3进4` / `M天N板` 最高标）、深水大弱转强捕捉、以及字头/题材交集首板** 的盘中结构化观察设计。

> [!IMPORTANT]
> **与 [`intraday-radar`（威科夫盘中高频雷达）](../intraday-radar/SKILL.md) 彻底物理隔离**：
> * **`intraday-radar`（威科夫模式）** 关注的是“低位地量蓄势、ETF深V回踩 `VWAP` 低吸潜伏（不追高 `>+3%`）”的均值回归与机构波段结构；
> * **`limit-up-hunter`（游资抓妖模式）** 关注的是“全市场连板梯队辨识度、情绪分歧转一致、右侧突破早盘前高/封板确认”的短线动量接力结构。
> * **严禁串台**：在本技能激活时，将“嫌前排涨太高去买后排平盘票”和“跟风股冲高回落破均线去低吸”与短线接力逻辑严格区分。

## 一、 六条盘中观察假设与扫描阈值（Working Hypotheses）

> [!NOTE]
> **证据等级声明（遵循 `AGENTS.md` Strategy Evidence Rule 5）**：
> 以下 6 条规则提炼自早盘连板接力与首板分时结构观察。在完成跨市场阶段（牛/熊/震荡）的多日历史回放与净摩擦收益验证前，所有规则在扫描器中均作为 **盘中结构化观察标签（Observation Tags）** 呈现，供人工盯盘辅助决策，不直接作为无人值守自动交易硬门槛。

### 假设 1：【昨日涨停/连板池 100% 全量跟踪、逐级晋级PK记分牌与断板反包同级提权】
* **观察逻辑**：昨日所有非 ST 涨停股（`1板`、`2板`、`3板`、`4板+`）及近 10 日高频断板反包人气标（`M天N板`，满足 `6天>=3板` 或 `10天>=5板`）应 **100% 全量保留并完整输出在 `[0] 昨日涨停/连板池今日晋级PK记分牌 & 全量监控`**（不截断行数）。顶部通过 `summarize_promotion_battle` 逐级汇总 `N进N+1`、`1进2`、`断板反包` 的 **晋级封板率、均线上待晋家数、冲板派面家数与绿盘掉队家数**（并同步注入飞书狙击卡），严防只看单票分时而漏判梯队断层与晋级淘汰赛况。排序时将断板反包高标（`prev_boards == 0` 但具备 `M天N板` 标签）赋予与 `1进2` 相同的梯队层级（`ladder_tier = 1`）并按实时涨幅排序，防止高标首阴反包被排在弱势绿盘 `1进2` 之后。

### 假设 2：【“深水穿云箭 / 盘中大长腿 / 高标首阴反包 + 5m 缩量锁仓” 弱转强分时结构】
* **扫描器量化阈值（代码与文档严格对齐）**：
  1. **连板/高标池弱转强（`_is_ladder_reversal`，要求当前翻红 `last_pct >= 0.0%` 且站稳分时均线 `last_price >= VWAP - 0.001`）**，满足以下任一分支即进入 `[3]`：
     * **竞价深水穿云箭**：`open_pct <= -2.5%` 且 `diff_from_open >= +6.0%`；
     * **盘中深水大长腿**：盘中下杀 `low_pct <= -3.0%`，从日内低点拉升幅度 `rebound_from_low (last_pct - low_pct) >= +7.0%` 且 `last_pct >= +1.5%`；
     * **高标首阴反包穿云箭**：断板反包高标（`prev_boards == 0` 且有 `M天N板` 标签）满足 `open_pct <= +1.0%` 且 `diff_from_open >= +6.0%`。
  2. **首板深水穿云箭与盘中大长腿（`_is_first_board_reversal`，`prev_boards == 0` 且无 `M天N板`、未封板、站稳 `VWAP`、成交额 `>= 1.0亿`）**：
     * `10cm` 主板要求 `last_pct >= +2.0%`，且满足「竞价深水 `open_pct <= -2.5%` 且 `diff_from_open >= +6.0%`」或「盘中深水 `low_pct <= -3.0%` 且 `rebound_from_low >= +8.0%`」；
     * `20cm` 创业板/科创板按涨跌幅比例缩放，要求 `last_pct >= +5.0%`，且满足「竞价深水 `open_pct <= -2.5%` 且 `diff_from_open >= +11.0%`」或「盘中深水 `low_pct <= -3.0%` 且 `rebound_from_low >= +13.0%`」。
  3. **5 分钟 K 线结构与右侧买卖点验证（`FiveMinSummary`）**：
     * **首根 5m K 线冲劲与首K低点防守（`first_5m_surge_pct` / `held_first_5m_low`）**：统计 `09:35` 首根 5m K 线 `(high - open) / prev_close` 及后续 5m K 线是否全程守住首根 5m K 线最低价（`守首K低` vs `破首K低`）。凡持仓股命中当日共振主线且满足 `>=VWAP` + `守首K低`，避免早盘回踩均线时轻易卖飞；
     * **分时回踩缩量比（`min_vol_ratio`）与伪锁仓过滤**：后续早盘 5m K 线最小成交额与首根 5m K 线成交额之比；仅当 `min_vol_ratio <= 15%`（`0.15`）且距日内高点未超时（`bars_since_high < 12` 即 `<60m`）时标记 `(<=15%锁仓)`，防止将午后摸高不封的久盘滞涨误判为锁仓；
     * **右侧突破早盘高点确认（`broke_morning_high`）与高点滞涨时长（`距高Xm`）**：突破 `09:30~09:45` 前三根 5m K 线最高价 `High_morning` 时标注 `过早高`，若距日内最高点已超过 2 根 5m K 线则同步展示 `过早高|距高Xm`（未过早高则标注 `横盘Xm`）。
  4. **高标深水摸高不封与首板摸板炸开·半山腰接盘风险标注（`reversal_risk_tag`）**：
     * 针对摸高 `high_pct >= +8.0%` 但未封板、且存在巨幅日内获利盘或准摸板炸开（`rebound_from_low >= +9.0%`、`ladder_tier >= 1` 或 `high_pct >= +9.2%`）的个股：
       * 若从高点回撤 `drop_from_high <= -4.5%`：标注 **`[🚨冲板失败大幅回落·做T砸盘兑现]`**；
       * 若距日内高点已横盘超过 75 分钟（`bars_since_high >= 15`）：标注 **`[🚨摸高久盘不封(>75m)·防尾盘做T砸盘]`**；
       * 若距高点已满 30 分钟（`bars_since_high >= 6`）或回撤 `<= -2.0%`：标注 **`[⚠️冲板未封回落·禁半山腰追高]`**；
       * 若早盘试盘弱（`first_5m_surge_pct < 1.8%`）、午后突发脉冲放量（`max_pm_amt >= 4.0 * morning_avg`）后最新 5m K 线量能即衰减 `>= 40%` 且涨幅滞留在 `< +7.5%`：标注 **`[⚠️午后量化脉冲衰竭·防冲高回落]`**；
       * 反之若刚翻上均线、处于 `1.5% <= last_pct <= 5.5%` 且距 `VWAP <= 2.5%`：标注 **`[✅贴均线弱转强低吸区]`**。
  5. **A股异动监管梯度标记与最高板同宗低价伴生小弟雷达（`reg_risk_tag` & `find_dragon_companions` -> `[B]`）**：
     * 对 `prev_boards >= 5` 标注 **`[⚡高标重度异动监管]`**，对 `prev_boards >= 3` 或 `M天5板+` 标注 **`[⚠️异动监管观察]`**；
     * 当全场空间龙（`prev_boards >= 3` 且封板或站稳均线大涨）面临高标异动监管时，自动在 **`[B] 最高板/空间龙同宗低价伴生小弟雷达`** 中绕过 `last_pct >= 3.5%` 门槛，扫描同核心字根/同行业、`0异动`（`prev_boards == 0` 且无 `M天N板`）、低价（`<= 15元`，优先 `<= 10元`）、站稳 `VWAP` 且 `守首K低` 的主板伴生小弟；
     * 支持通过 `--max-price 15`（或 `--max-price 10`）一键过滤 `[3]`、`[B]`、`[5]` 候选池股价上限，并在 `[5]` 低吸候选排序中优先提权 `<= 10元 / <= 15元` 低价股。

### 假设 3：【最高标竞价超预期观察 & 同花顺/东方财富实时每日热点下钻成分股雷达】
* **观察逻辑**：每日 `09:25` 竞价与 `09:35~10:00` 早盘主升窗口，除了检查全场最高连板活口及高换手抱团标（`M天N板`）外，通过 [realtime_concepts.py](./scripts/realtime_concepts.py) 与 `detect_fermenting_themes` 对全市场强股（已封板或站稳 `VWAP` 且 `last_pct >= +3.5%`）执行 **四步法实时主线雷达（`[5] 盘中题材/字根共振发酵雷达`：今日热点 → 下钻成分股 → 清点援军 → 看大哥打小弟）**：
  * **同花顺 + 东方财富实时概念主引擎（离线自动回退词根/行业种子库）**：
    1. **同花顺实时概念热榜与成熟度标签（`fetch_ths_hot_plates`）**：实时拉取同花顺热榜概念排名与成熟度标记（如 `首次上榜` 识别突发新题材、连续上榜识别存量主线）；
    2. **同花顺涨停风口板块与游资涨停归因（`fetch_ths_limit_up_blocks`）**：实时提取当日涨停风口板块最高标身位及封板股精确游资归因，解决静态行业分类漏判跨界新题材的盲区；
    3. **东方财富领涨概念援军统计与成分股全标签下钻（`fetch_em_hot_concepts` + `fetch_em_stock_concepts`）**：并发批量拉取活跃股实时概念标签与领涨板块红盘家数（`东财红盘援军:XX家`），离线测试时无感回退至内置词根库 $\cup$ Tushare 行业分类引擎；
    4. **高频 2 字词根簇（名字字辈线）**：同步提取强股名称中的高频 2 字词根（剔除通用词后同字根强股 `>= 3` 只自动生成 `『XX』字辈` 簇）；
  * **发酵触发、梯队完整度与后排小弟正负反馈（`_evaluate_theme_echelon` & `tag_theme_front_runner`）**：当某一主题/行业/字辈簇满足 **已涨停 `>= 2` 只**（或已涨停 `>= 1` 只且强股 `>= 4` 只）时，不仅统计已涨停家数，还同步穿透核验该主题内 **昨日连板晋级人数 vs 昨日连板深跌掉队（`<=-2.5%`）及日内冲高破均线派面小弟人数**：
    * **`[🏆梯队完整(...)·小弟正反馈]`**（`echelon_score = +2`）：连板晋级 `>= 2` 只且掉队派面小弟人数不超过晋级人数（晋级占比 `>= 45%`），在同 `monster_tier` 内优先提权；
    * **`[⚠️前排独食/后排派面·掉队X只(...)·慎追后排]`**（`echelon_score = -1`）：虽然前排有缩量锁死高标，但同题材后排掉队/炸板派面小弟 `>= 3` 只且超过晋级人数 `1.5x`——`select_sniper_targets` 严格坚守 **“妖气第一（`monster_tier` 永远第一优先级）”** 原则，仅拦截该板块内无强妖股基因的普通 `0板` 后排跟风杂毛（`monster_tier < 2`），**绝不误杀去弱留强独立抱团的连板活口、N 字二波真妖胚（`monster_tier >= 2`）或 `10日>=2板` 独立走妖标的**；
    * 未封板活口分级标注：
      * **`[🎯主线妖股苗子·N字基因贴均线守首K]` / `[🎯主线低吸首选·贴均线守首K]`**：`3.0% <= last_pct <= 6.8%`、距离 `VWAP <= 2.5%` 且全程 `守首K低`；
      * **`[⚡主线前排冲板博弈]`**：`last_pct >= 6.8%` 且 `守首K低`、无久盘滞涨警告；
      * **`[⏸️同簇跟风观察(破首K低或偏离均线)]`** 或透传 `[⚠️/🚨]` 久盘风险标签；
  * **持仓股全幅主线共振与连板/跟风分层去弱留强诊断（`--holdings` -> `[H]` / `_holding_action_tag`）**：传入 `--holdings 600001.SH:10.00,000002.SZ:8.50` 时，对持仓股执行全涨幅段主线匹配与结构分层处理：
    * 站稳 `VWAP` + 命中共振主线 + `守首K低`：标注 **`[🛡️主线共振(...)+守首K低·格局防卖飞]`**；
    * 水下 `< VWAP` 结构分层：对连板/抱团高标（`prev_boards >= 2` 或具备 `M天N板` 标签），若缩量换手（`min_vol_ratio <= 0.30`）且跌幅可控（`last_pct > -6.0%`），标注 **`[🛡️连板分歧缩量换手·宜分批锁利留底仓看均线承接]`**；对跟风股或放量/深跌破位标的，维持 **`[🚨破VWAP且破首K低·果断去弱留强]`**；
  * **全市场派面温度计、妖股基因筛子（剔除死鱼大盘股）、近 60 日套牢盘排雷与飞书目标价直推（`sniper_feishu.py` -> `[S]` & `--feishu-notify`）**：
    * **妖股基因与流通盘/换手率硬门槛（`has_monster_gene` / `has_consec_gene` / `monster_tier`）**：基于近 60 个交易日涨停基因、最高连板高度（`max_consec_60d`）与最新流通市值/换手率，剔除「近 60 日 `0` 涨停」、「流通市值 `> 200亿`（除非近 10 日 `>=2` 板且换手 `>=8%`）」、「`120~200亿` 但近 10 日无涨停或换手 `<5%`」及「换手率 `<2.5%` 织布机死水盘」的主线跟风大块头；排序优先提权 **近 10 日刚出过首板/连板强势揉搓的 N 字二波苗子（`monster_tier == 3`）** 与 `<= 100亿` 多板活跃小盘股（`monster_tier == 2`）；
    * **A股 `T+1` 双轨正期望买点门控（`_classify_t1_entry_mode`）**：针对 `T+1` 次日跳空低开吞噬日内薄垫的结构痛点，`select_sniper_targets` 仅放行两条正期望买点轨道：
      1. **`[🚀T+1水上接力·真连板基因]`**（`+2.5% <= last_pct <= +7.2%` 且贴 `VWAP`）：水上出手**强制要求具备真连板溢价基因（`has_consec_gene`：`prev_boards >= 1`、`M天N板`、`max_consec_60d >= 2`、`lu_10d >= 2` 或 `lu_60d >= 3`）**，一票否决近 60 日仅偶发单板、从不连板的“一日游体质”水上追高；
      2. **`[🌊T+1水下承接·博大振幅垫]`**（`-2.5% <= last_pct < +2.5%`）：日内深水洗盘 `low_pct <= -3.0%` 后强力拉起 `rebound_from_low >= +3.5%` 并率先站稳 `VWAP`（`0.0 <= vwap_gap <= 2.8%`），在平盘/水下拐点切入吃 `8%~12%+` 日内大振幅安全垫，无惧次日低开；
    * **流动性与早盘开盘结构适配（`select_sniper_targets`）**：流动性门槛设为 `amount_yi >= 0.6亿`，兼容低价小盘股刚突破 `+3%` 时的早盘成交量级；仅当首根 5m 大幅冲高（`first_5m_surge_pct >= +3.0%`）时要求回踩缩量 `min_vol_ratio <= 0.25`，首根 5m 温和开盘标的只要满足 `守首K低` 且 `过早高`（`broke_morning_high`）即可入选；
    * **派面/封板比情绪门控（`compute_market_sentiment`）**：冲高回落派面家数达封板家数 `>= 1.35x` 且绿盘 `>= 1.25x` 红盘时判定为 **`[🌩️早盘冲高派面潮]`**，`10:40` 前过滤未过早高或成交 `< 1.5亿` 的左侧票；
    * **近 60 日日线套牢盘排雷（`evaluate_daily_overhead`）与飞书直推**：剔除近 5~15 日存在大阴/跌停套牢盘或上方 60 日套牢区厚重的标的，动态从 `FEISHU_USER_OPEN_ID` 或 `lark-cli auth status` 解析接收方（零隐私硬编码），按当日去重缓存推送目标价与防守价；
  * 支持通过 `--keyword` 在 `[6]` 中输出指定词条的全部成分股前后排分布。

### 假设 4：【双主线交集优先假设（`热点A` $\cap$ `热点B`）与弱势行业规避】
* **观察逻辑**：当盘面同时存在两条主线（如【连板高标字头/题材 A】与【当日领涨行业主线 B】）时，首板观察优先聚焦两者的交集标的，并警惕主业处于当日领跌行业的纯名字跟风标的。

### 假设 5：【`10:30` 时间截断观察：警惕前排满板后的平盘后排脉冲】
* **扫描器量化阈值（代码与文档严格对齐）**：
  * 当指定 `--keyword` 主题/字辈内**已封死涨停家数 `front_lu_count >= 4` 只**，且行情快照时间（`Asia/Shanghai`）满足 **`now_hhmm >= "10:30"`** 时；
  * 对仍处于平盘附近 **`0.0% <= last_pct <= +2.5%`** 的未涨停同字辈个股，统一标注 **`[⚠️10:30后平盘观察]`**，提示后排跟风衰竭风险。

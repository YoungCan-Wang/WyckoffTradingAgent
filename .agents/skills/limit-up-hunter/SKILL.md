# A股游资抓板抓妖与连板梯队实战规程 (Limit-Up Hunter Skill)

本技能专为 **A股超短连板接力、龙头晋级（`1进2` / `2进3` / `3进4` / `最高标`）、深水大弱转强捕捉、以及跨年妖股字头/题材交集首板** 设计。

> [!IMPORTANT]
> **与 [`intraday-radar`（鑫仔威科夫盘中雷达）](../intraday-radar/SKILL.md) 彻底物理隔离**：
> * **`intraday-radar`（威科夫模式）** 赚的是“低位地量蓄势、ETF深V抄底、回踩 `VWAP` 低吸潜伏（不追高 `>+3%`）”的均值回归与机构波段钱；
> * **`limit-up-hunter`（游资抓妖模式）** 赚的是“全市场最高辨识度、情绪分歧转一致、右侧突破前高/打板确认”的龙头溢价钱。
> * **严禁串台**：在本技能激活时，**彻底关闭“嫌前排涨太高去买后排平盘票”和“连板股冲高回落到均线去低吸”的威科夫思维**！

## 一、 游资抓妖六大死律（盘中推票硬门槛，违反任意一条直接过滤）

### 铁律 1：【昨日连板池 100% 全量监控，严禁 `09:25` 因低开剔除】
* 昨日所有非 ST 涨停股（`1板`、`2板`、`3板`、`4板+`）必须 **100% 全量保留在盘中扫描池**。
* **严禁**在 `09:25` 集合竞价因为某只连板股低开 `-4% ~ -7%` 就将其判定为“淘汰”并移出监控（经典案例：`2026-11-06` 的 `2进3` 真龙 **`002388.SZ 新亚制程`** 竞价低开 `-5.12%` 排倒数第一，但开盘 5 分钟爆量拉红，全天成为唯一换手晋级 3 板的真龙）。

### 铁律 2：【`09:30~09:40` “深水穿云箭 + 平盘缩量锁仓” S级弱转强法则】
* 在 `2进3` / `3进4` 梯队中，最高优先级捕捉以下分时形态：
  1. **竞价水下深开**（`-2.5% ~ -7.0%`），释放隔夜恐慌核按钮；
  2. **`09:30 ~ 09:35` 首根 5 分钟 K 线爆量穿云箭**：从开盘价向上猛拉 `>= +6.0%` 并直接翻红突破昨收价（`last_price >= prev_close`）；
  3. **平盘/均线极度缩量锁仓**：冲高后回踩昨收平盘线或 `VWAP` 不破，5 分钟成交额阶梯式萎缩至首根 K 线的 `15%` 以下（主力吃进恐慌盘后锁仓）；
  4. **右侧买点**：缩量横盘后**放量突破早盘第一波高点（`High_morning`）** 的瞬间（或平盘锁仓确认后的首次放量抬头）。

### 铁律 3：【最高标竞价超预期优先律 & 字头/属性同步挂载】
* 每日 `09:25` 竞价定格后，第一眼先看**全场最高连板活口**（及昨日 `>45%` 死亡换手高标）：
  * 若昨日爆天量换手的高标，今日竞价在大盘低开背景下居然**平开或红盘高开（`>= 0%`）**（如 `002086 东方海洋` 昨日 `53%` 换手次日竞价 `+1.66%` 高开），直接判定为**全场最高级别情绪超预期**！
  * **必须在 `09:30` 开盘第一时间**同步挂载其 **【名字同字辈（如“东方XX”）】+【核心主业】** 的前排异动扫描，绝不等到高标 `10:00` 封死涨停后才后知后觉去挖后排。

### 铁律 4：【双主线交集法则（`热点A` $\cap$ `热点B`），一票否决垫底行业】
* 当盘面同时存在两条主线（如【连板最高标字头/题材 A】与【当日最强行业主线 B】）时，首板套利**只买两者的交集股**：
  * **正例**：`东方日升 / 东方新能`（【东方字辈】$\cap$【光伏绿电】）、`东方精工`（【东方字辈】$\cap$【机器人】）、`鑫铂股份`（【光伏】$\cap$【铝边框】）。
  * **一票否决（反例）**：若某只字辈/跟风股的主业处于**当日全市场跌幅前 3 的垫底行业**（如通信硬件暴跌日里的 `600776 东方通信`），无论名字多正宗，一律一票否决！

### 铁律 5：【`10:30` 时间截断律：绝不买 `10:30` 后还在平盘晃悠的后排跟风】
* 题材首板或字辈玄学炒作，黄金窗口仅限 **`09:30 ~ 10:15`**，且只看板块内**前 2~3 只涨停或涨速第一的领涨先锋**。
* **硬性截断**：到了 **`10:25 ~ 10:30` 之后**，如果同题材/同字辈前排已经涨停 `>= 4` 只，此时还在平盘线附近（`0% ~ +2.5%`）小幅脉冲的后排票（如 `2026-11-06 10:30` 的 `002167 东方锆业`），**100% 是量化监测词条后的程序化诱多点火**，散户一接盘即阴跌，**10:30 后严禁开仓任何未上板的后排跟风首板**！

### 铁律 6：【一字断层禁做换手 `1进2` & 中位接力严禁“破 `VWAP` 半路抄底”】
1. **顶楼一字断层日放弃换手 `1进2`**：
   * 若当日 `3板 / 4板 / 5板` 核心高标在竞价全部一字涨停锁死（无换手给后排留气口），且大盘指数低开 `<= -1%`，当日**换手 `1进2` 晋级率极低**（昨日首板获利盘集中兑现，如 `600481 双良节能`），原则上放弃换手 `1进2`。
2. **中位连板（`2进3` / `3进4`）只做“右侧过前高”，绝不低吸冲高回落股**：
   * 连板接力股早盘冲高 `>= +6%` 未能封板并掉头回落跌破 `VWAP`（或冲高回落横盘超过 `15 分钟` 不创新高，如 `002309 中利集团`、`002160 常铝股份`、`002088 鲁阳节能`），直接判定为**日内派发淘汰**！
   * 在 `T+1` 制度下，**严禁在连板股冲高回落跌破 `VWAP` 时去“逢低吸纳”**——连板股没有均值回归，晋级失败就是单边大面。

## 二、 标准执行脚本与盘中工作流

运行 [ladder_scanner.py](./scripts/ladder_scanner.py) 一键扫描全市场实时涨停梯队、深水弱转强活口、双主线共振首板与冲高回落陷阱名单：

```bash
# 扫描当前全市场涨停梯队、深水穿云箭弱转强与冲高回落黑名单
.venv/bin/python .agents/skills/limit-up-hunter/scripts/ladder_scanner.py

# 叠加指定字辈/关键词（如“东方”、“铝”）扫描前排先锋与后排诱多区分
.venv/bin/python .agents/skills/limit-up-hunter/scripts/ladder_scanner.py --keyword 东方
```

### 盘中四步决策流程：
1. **`09:25 ~ 09:29`（竞价定性）**：
   * 识别一字连板高度与最高换手标是否超预期红开；
   * 锁定全量昨日连板池（不删任何深水低开票）。
2. **`09:30 ~ 09:40`（首轮弱转强与先锋卡位）**：
   * 优先抓 **`2进3` / `3进4` 深水穿云箭（低开 `<= -2.5%` 后 5 分钟拉升 `>= +6%` 翻红）**；
   * 若做首板，只抓 `09:40` 前站稳 `VWAP` 且具备 **双主线交集** 的领涨第 1 先锋。
3. **`09:40 ~ 10:25`（缩量锁仓突破段）**：
   * 监控早盘第一波翻红后、在平盘/均线处缩量横盘锁仓的连板活口，在**放量突破早盘高点（`High_morning`）** 时右侧跟随。
   * 凡是摸板炸开或冲高 `+7%` 回落跌破 `VWAP` 的标的，立即移入当日黑名单（`BLACKLIST`）。
4. **`10:30` 之后（垃圾时间防守律）**：
   * 停止一切后排跟风首板开仓；只观察已持仓标的封单及次日去弱留强计划。

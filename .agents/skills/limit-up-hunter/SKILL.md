# A股游资抓板抓妖与连板梯队盘中观察规程 (Limit-Up Hunter Skill)

本技能专为 **A股超短连板接力、龙头晋级（`1进2` / `2进3` / `3进4` / `M天N板` 最高标）、深水大弱转强捕捉、以及字头/题材交集首板** 的盘中结构化观察设计。

> [!IMPORTANT]
> **与 [`intraday-radar`（鑫仔威科夫盘中雷达）](../intraday-radar/SKILL.md) 彻底物理隔离**：
> * **`intraday-radar`（威科夫模式）** 关注的是“低位地量蓄势、ETF深V回踩 `VWAP` 低吸潜伏（不追高 `>+3%`）”的均值回归与机构波段结构；
> * **`limit-up-hunter`（游资抓妖模式）** 关注的是“全市场连板梯队辨识度、情绪分歧转一致、右侧突破早盘前高/封板确认”的短线动量接力结构。
> * **严禁串台**：在本技能激活时，将“嫌前排涨太高去买后排平盘票”和“连板股冲高回落破均线去低吸”与短线接力逻辑严格区分。

## 一、 六条盘中观察假设与扫描阈值（Working Hypotheses）

> [!NOTE]
> **证据等级声明（遵循 `AGENTS.md` Strategy Evidence Rule 5）**：
> 以下 6 条规则提炼自 `2026-11-06` 早盘连板接力与首板实盘复盘（单日单截面样本 `N=1`）。在完成跨市场阶段（牛/熊/震荡）的多日历史回放与净摩擦收益验证前，所有规则在扫描器中均作为 **盘中结构化观察标签（Observation Tags）** 呈现，供人工盯盘辅助决策，不直接作为无人值守自动交易硬门槛。

### 假设 1：【昨日涨停/连板池 100% 全量跟踪，不因 `09:25` 低开剔除】
* **观察逻辑**：昨日所有非 ST 涨停股（`1板`、`2板`、`3板`、`4板+`）及近 6 日高频断板反包妖股（`M天N板`，满足 `N >= 3`）应 **100% 全量保留在 `[0] 昨日涨停/连板池今日晋级全量监控`**。
* **背景案例**：`2026-11-06` 的 `2进3` 标的 **`002388.SZ 新亚制程`** 在 `09:25` 集合竞价低开 `-5.12%`，但开盘首根 5 分钟 K 线放量拉升翻红，全天换手晋级 3 板。若在 `09:25` 按竞价涨跌幅截断，会直接漏掉深水弱转强晋级活口。

### 假设 2：【`09:30~09:45` “深水穿云箭 + 缩量锁仓” 弱转强分时结构】
* **扫描器量化阈值（代码与文档严格对齐）**：
  1. **竞价水下深开**：`open_pct <= -2.5%`；
  2. **开盘向上拉升幅度（区分连板梯队与 10cm/20cm 首板）**：
     * **连板梯队弱转强（`prev_boards >= 1` 或 `M天N板`）**：`diff_from_open >= +6.0%`，当前翻红（`last_pct >= 0.0%`）且站稳分时均线（`last_price >= VWAP - 0.001`）；
     * **首板深水穿云箭（`prev_boards == 0`，成交额 `>= 1.0亿`）**：`10cm` 主板要求 `diff_from_open >= +6.0%` 且 `last_pct >= +2.0%`；`20cm` 创业板/科创板按涨跌幅比例缩放，要求 `diff_from_open >= +11.0%` 且 `last_pct >= +5.0%`；
  3. **5 分钟 K 线结构验证（`FiveMinSummary`）**：
     * **首根 5m K 线冲劲（`first_5m_surge_pct`）**：统计 `09:35` 首根 5m K 线 `(high - open) / prev_close` 及是否收红（`close >= prev_close`）；
     * **分时回踩缩量比（`min_vol_ratio`）**：后续 5m K 线最小成交额与首根 5m K 线成交额之比；当 `min_vol_ratio <= 15%`（`0.15`）时标记 `(<=15%锁仓)`；
     * **右侧突破早盘高点（`broke_morning_high`）**：最新 5m 收盘价是否突破 `09:30~09:45` 前三根 5m K 线最高价 `High_morning`（标注 `过早高` vs `横盘Xm`）。

### 假设 3：【最高标竞价超预期观察 & 字头/属性联动扫描】
* **观察逻辑**：每日 `09:25` 竞价定格后，优先检查全场最高连板活口及高换手抱团标（`M天N板`）：
  * 若昨日爆天量换手的高标在指数低开日竞价平开或红盘高开（`open_pct >= 0%`，如 `002086.SZ 东方海洋` `6天4板` 爆量次日竞价 `+1.66%` 高开），提示情绪超预期观察信号；
  * 支持通过 `--keyword`（如 `--keyword 东方`）同步扫描同字辈/同主题标的的前后排身位分布。

### 假设 4：【双主线交集优先假设（`热点A` $\cap$ `热点B`）与弱势行业规避】
* **观察逻辑**：当盘面同时存在两条主线（如【连板高标字头/题材 A】与【当日领涨行业主线 B】）时，首板观察优先聚焦两者的交集标的（如 `东方日升 / 东方新能` = 【东方字辈】$\cap$【光伏绿电】、`东方精工` = 【东方字辈】$\cap$【机器人】），并警惕主业处于当日领跌行业的跟风标的（如通信板块领跌时的 `600776.SH 东方通信`）。

### 假设 5：【`10:30` 时间截断观察：警惕前排满板后的平盘后排脉冲】
* **扫描器量化阈值（代码与文档严格对齐）**：
  * 当指定 `--keyword` 主题/字辈内**已封死涨停家数 `front_lu_count >= 4` 只**，且行情快照时间（`Asia/Shanghai`）满足 **`now_hhmm >= "10:30"`** 时；
  * 对仍处于平盘附近 **`0.0% <= last_pct <= +2.5%`** 的未涨停同字辈个股（如 `2026-11-06 10:30` 的 `002167.SZ 东方锆业`），统一标注 **`[⚠️10:30后平盘观察]`**，提示后排跟风衰竭风险。

### 假设 6：【一字断层日换手 `1进2` 谨慎观察 & 冲高破 `VWAP` 风险标注】
* **扫描器量化阈值（代码与文档严格对齐）**：
  1. **顶楼一字断层观察**：当 `3板+` 高标全部一字涨停锁死（`open == low == limit_up_price`）且指数低开时，提示换手 `1进2` 兑现压力；
  2. **冲高回落破 `VWAP` 观察名单（`traps`）**：对日内曾经摸高 `high_pct >= +6.0%`、随后从高点回撤 `drop_from_high <= -4.5%` 且跌破分时均线（`last_price < VWAP - 0.001`）的未封板个股（优先按昨日连板高度排序，如 `2进3` 冲高回落的 `002309.SZ 中利集团`），归入 `[4] 冲高回落破VWAP观察名单` 并标注 **`[❌冲高破均线观察]`**，以及结合 5m K 线标注未创新高持续时间（`横盘Xm`）。

## 二、 标准执行脚本与输出说明

运行 [ladder_scanner.py](./scripts/ladder_scanner.py) 一键拉取全市场行情、近 6 日连板梯队高度（自动缓存至 `~/.wyckoff/cache/prev_ladder_<YYYYMMDD>.json`）与候选池 5 分钟 K 线结构：

```bash
# 扫描全市场昨日连板晋级池、一字板、换手板、深水弱转强与冲高破均线观察名单
.venv/bin/python .agents/skills/limit-up-hunter/scripts/ladder_scanner.py

# 叠加指定字辈/关键词（如“东方”、“铝”）扫描前排先锋与 10:30 后平盘后排观察标签
.venv/bin/python .agents/skills/limit-up-hunter/scripts/ladder_scanner.py --keyword 东方
```

* **涨停与一字板精确口径**：使用 `Decimal` 四舍五入精确计算主板（`10%`）与双创（`20%`）涨停价 `round(prev_close * ratio, 2)`，仅当 `open == low == limit_up_price` 时判定为一字板（`is_one_word`），并自动剔除北交所（`.BJ`）、`ST` 及上市前 5 日无涨跌幅限制新股（`N`/`C` 开头）。
* **行情时间戳口径**：优先提取行情快照自身的 `timestamp`（转换为 `Asia/Shanghai` 时区），确保盘中与盘后复盘的时间截断判定一致。

## 三、 待验证样本口径与回测验证协议 (Validation Protocol)

在将上述任何一条“观察假设”升级为生产级硬性过滤门槛前，必须基于历史日线与 5 分钟高频数据完成跨市场周期的回放验证（遵循 `AGENTS.md` Strategy Evidence Rules 1–9，扣除双边交易摩擦 `core.trade_friction.round_trip_cost_pct() ≈ 0.202%`）：

| 假设编号 | 待验证样本集（Universe & Horizon） | 关键评估指标（扣除 `~0.202%` 双边成本后） | 升级为硬门槛的验证标准 |
| :--- | :--- | :--- | :--- |
| **假设 1 & 2**<br>（连板深水弱转强 + 5m 缩量锁仓） | 过去 120 个交易日所有非 ST 昨日涨停股（`prev_boards >= 1`），筛选 `open_pct <= -2.5%` 且首根 5m 拉升翻红样本 | 对比「5m 缩量 `<= 15%` 后突破早盘高点」vs「直接追高未缩量样本」的当日封板率、次日开盘/收盘净超额收益及日均触发数 | 跨震荡/上升/退潮三个阶段净期望收益显著为正，且优于未缩量基准组 |
| **假设 4**<br>（双主线交集 vs 垫底行业跟风） | 过去 120 个交易日同字辈/同概念爆发日（前排涨停 `>= 4` 只）的所有同词条成分股 | 对比「主业属于当日涨幅前 5 行业」vs「主业属于当日跌幅前 3 行业」的当日封板率与次日净溢价 | 垫底行业组次日净期望收益显著为负且跨周期稳健 |
| **假设 5**<br>（`10:30` 后平盘后排脉冲） | 同主题前排涨停 `>= 4` 只的交易日中，`10:30` 时仍处于 `0.0% ~ +2.5%` 且午盘前出现分时脉冲的后排样本 | 当日最终封板率、当日收盘相对脉冲高点回撤、次日开盘净收益 | 若当日封板率 `< 10%` 且次日净收益均值显著为负，方可升级为硬性禁入规则 |
| **假设 6**<br>（中位连板冲高 `>=+6%` 回落破 `VWAP`） | 过去 120 个交易日 `2进3` / `3进4` 候选池中，早盘摸高 `>= +6.0%` 后回撤 `>= 4.5%` 且跌破 `VWAP` 的样本 | 水下破 `VWAP` 位置买入后的当日回封率 vs 收盘平均亏损幅度及次日核按钮比例 | 若水下回封率极低且净期望显著为负，升级为盘中右侧过滤规则 |

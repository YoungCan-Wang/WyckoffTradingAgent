# A 股研究发现与执行验收

## 变更边界

本轮修复研究发现被展示/选择范围掩盖、推荐收益归因和历史诊断写入风险。没有放宽市场闸门、跨日确认、OMS、止损、高位过滤或最终 AI / 行业额度，也没有修改线上历史推荐、持仓、订单或数据库结构。

| 层次 | 本轮行为 | 不代表什么 |
|---|---|---|
| 研究发现 | 全部有效主线买点条目参与合并；L2/近 L2、候选、主线、趋势雷达并集保留在原有 trace / 报告详情 / Agent 中 | 不代表已 confirmed 或可以买 |
| 解释 | 分开报告发现、信号、确认未评估与执行拦截；缺失统一分数时补 `mainline_score × 100` | 不改变最终额度或强制授予 AI 席位 |
| 时点 | 当日雷达优先，历史仅 TTL 内降级；拒绝未来快照 | 不宣称新闻、财务和概念映射已完整 point-in-time |
| 诊断 | as-run trace 可离线读取；当前配置回放进入共享只读 scope | 重放结果不冒充历史实际运行，也不写回推荐/信号 |
| 评估 | 修正每次推荐的入场和收益分母；保留缺价、未成熟和不可进入状态 | 不代表真实成交或已经取得正 alpha |

CLI 对大结果复用现有 `result_ref` 完整落盘，预览和跨工具交接保留研究计数及少量样例；不把“送审为零”压成“没有发现”。MCP 的现有筛选工具仅展示有大小上限的详细预览和完整分组代码索引，并明确未展开数量，不修改底层研究池或假称完整明细可由 MCP 取回。Web 现有独立推荐查询不在此轮新增页面或全量研究查询接口。

只读 scope 对已接入的共享写入适配器生效，保留原身份权限与服务端读取；进程内重叠 scope 仅在最后退出时恢复环境，工作线程也拒写。它不是数据库级只读账号或任意代码沙箱，不能撤销已发出的请求；诊断仍应在独立进程执行。

## 三种收益不能混用

1. **首次入池累计涨幅**：`recommendation_tracking.initial_price` 可能在同票重复推荐行中沿用首次价格。它用于跟踪长期走势，不是每次推荐都赚了该涨幅。
2. **逐次推荐事件**：按该行 `recommend_date` 后首根可用日线的开盘价测量，买入日记 0，H 表示此后 H 根观测日线，退出为第 H 根收盘。需要精确的信号日收盘、有效开盘与 OHLC，并检查带时区的 `created_at` 早于该市场开盘；发布过晚、缺价格、停牌或开盘涨停不顺延挑选更有利价格。`net_close_return_horizon_pct` 扣生产 `round_trip_cost_pct(code=...)`。
3. **现金组合**：经过选择、市场闸门、确认、可交易性、持有重叠、现金/持仓约束和退出模拟后的净值。只有这一层的同口径对照才能检验配置的组合收益变化，且仍不是券商实盘成交。

事件的 `price_touch_target` 是价格路径触达；`hit_target` 从该市场最早可卖日开始观察（A 股不计入场当天），仍不保证目标价成交。MFE/MAE 是价格路径，不是实际止盈止损。事件使用“观测 K 线”而非已验证完整交易日历，缺失整根行情或停牌导致的间隔仍是限制。日线也不能证明盘口排队、账户现金、跌停退出与实际滑点。

A 股交收前不得卖出的规则参见[上交所 2026 年交易规则 3.1.4](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)；本评估不把适用于回转交易品种的例外移用于普通 A 股。

推荐排序评估的候选资格还要求候选/参照组净收益样本完整、候选平均净收益和相对参照的净收益增量都大于零；高触价率不能抵消扣费亏损。这仍是样本内研究门槛，不能免除跨期、组合和参数稳定性验收。

所有事件保留在总分母中，`status_counts` 说明未成熟/不可评估原因；只有成熟有效事件进入净收益均值。全市场收益统计另披露候选、双端有效价格、缺价和低样本日剔除数；没有基准数据就不报告跑赢指数。

## 验收标准

- 可靠性：新增边界测试、完整测试、Ruff、质量门槛与 CI operational smoke 均须成功；排队/运行中不算通过。
- 暴露：输出每日 universe、各层候选、主线、闸门前后代码和实际交易差异。零暴露只能说明没有测到该改动，不能说明改动有效。
- 产物：每次回测的 `selection_coverage_*.json` 随原有产物保存每日选择分母与代码；它是选择暴露而非实际成交清单，现金执行差异仍须另行对账。
- 收益：比较同臂的扣费现金收益、回撤、成交数、基准超额和分段方向；单窗口正收益、少亏、研究召回增加或事后强势样本命中，均不足以证明稳定正收益。
- 组合：最终配置必须以组合对照为准，不能相加单项实验收益；任何单项候选也不自动晋级。
- 结论：结果未完成或证据受限时明确标记未验证；不得预先把本轮修复写成正收益策略。下列样本内结果不构成生产策略晋级或稳定正收益验收通过。

本地初轮完整测试为 4760 passed / 22 skipped，另通过 Ruff、函数长度门槛、workflow/dependency hygiene 和 daily-job dry-run；后续补充的适配器/预览边界仍需以最终提交的 CI 为准。LOC 门槛仅产生既有基线累计增长 warning，不等于本 PR 增长该比例。

有限兼容性验证：6 只合成事件、46 根行情、3 个确认日，真实 `PendingPool.write/tick → selection → execution gate → replay_signal_ledger → confirmation_only` 路径在基线与本轮源码分别执行。注入的主线研究条目 3→6、分数标签变化后，RISK_ON 同 5 只确认、同 4 笔现金成交；逐笔代码、日期、价格、仓位倍率、股数、盈亏与最终现金一致。半仓/短持有期样例一致，RISK_OFF 均零成交。该 fixture 不验证历史主线探测器或全窗收益，也不替代完整确认臂；新开盘现金时序有独立边界测试。

## 完成账本后的可复算比较

`scripts/compare_research_execution.py` 不重建信号或退出：读取完成的生产交易 CSV，复用生产现金模拟器，再按观测基准日历核对逐日净值。异常价格/仓位倍率、缺失或未知确认状态、重复交易身份、现金不平和基准缺口均不得被静默清洗。示例中的路径需替换为实际产物路径：

```bash
python scripts/compare_research_execution.py \
  --base-trades /path/to/base/trades.csv \
  --candidate-trades /path/to/candidate/trades.csv \
  --snapshot-dir /path/to/frozen-snapshot \
  --start 2025-01-01 --end 2026-09-04 \
  --style slot_equal_4 --slippage-pct 0.05 \
  --run-contract /path/to/run-contract.json \
  --output-dir /path/to/comparison
```

正式确认兼容臂改用 `--style confirmation_only`，不能把它与 `slot_equal_4` 交叉比较。`run-contract` 分别记录 base/candidate 的源版本、交易 CSV SHA256 和相同 settings（窗口、H、止损/退出、入场、市场闸门、pending、TopN、股票范围、历史长度、元数据、policy env、费用及输入哈希）；必需键由脚本 `verify_run_contract` 校验。脚本会绑定本次实际快照文件集、基准、name map 哈希，而不是只相信合同里填了相同字符串。此合同仍是运行来源声明，不是对未记录历史环境的追溯证明。

原生产日线入场路径允许开盘涨停等情况顺延至后续观测日，并存在缺开盘回退收盘的兼容行为；不能仅凭参数 `entry_price_mode=open` 就称为严格次日开盘。比较器保留全部账本，另核对推荐后首个基准交易日、实际入场日、价格来源与原始有效开盘价，披露延期或不匹配，不事后删除它们改善收益。开盘估值不得通过 OHLC 兼容函数以收盘填补；缺失估值需显式计数并阻断完整性判断。

输出 `comparison.json`、两组 `cash_trades.csv` 和 `daily_nav.csv`。主指标使用 `cash_periods` 的净收益与完整观测日历回撤；`cash` 中生产模拟器附带的事件日回撤不作为主回撤。`pre_cash_signal_diagnostics` 明确是现金筛选前信号，不可当真实成交。`filled_exposure_difference` 显示实际交易键和股数变化；没有合同或持仓日缺价时，`measurement_complete=false`。即使账对平且增量为正，`strategy_acceptance` 仍不自动通过，历史时点、跨阶段和生产执行适用性需要独立验收。

实际成交键共同 84 个，基线独有 15 个、PR 独有 19 个；共同键中 39 个股数不同，共同价格一致。独有键净盈亏差约 +7745.899 元，共同键仓位路径差约 -941.748 元，合计 +6804.151 元，与 10 万元初始资金下的收益增量一致。34 个独有键涉及 21 个信号日，最早 2025-02-05、最晚 2026-08-07；其中 18 个早于任何股票首次达到 320 根的 2025-07-25，10 个早于首次达到 250 根的 2025-04-14。两个账户最大回撤的峰谷都在 2025-03-12 至 07-15，处于全池尚无 320 根历史的阶段。此日期分层只是预热覆盖标签，不证明每只交易股票的指标历史充分，未据此删除样本或重选窗口。

分母来源分别保留：相同快照/未改加载路径支持固定池范围声明；PR 的逐日 `selection_coverage` 实测覆盖 386 个实际漏斗日；基线只有其原有日志和完整交易账本，没有同版逐日覆盖文件。即使最终信号累计数与交易观察数完全对上，也不能据此声称双方 L1/L2/L3 每日分母已独立实测一致。

结论是**该冻结样本的研究选择现金净收益有正增量，但回撤扩大、分期不一致、平均信号质量未同步改善**。叠加静态行业/概念、预热与来源证据限制，不能据此晋级生产策略或认定已解决线上正收益问题。没有根据结果继续调参；PR 保持草稿，不因技术测试通过而自动晋级。可复算产物在本地 `analysis/backtest_acceptance/comparison_off_open_v1/`，运行契约为 `off_run_contract.json`，原始账本与行情不随 PR 提交。

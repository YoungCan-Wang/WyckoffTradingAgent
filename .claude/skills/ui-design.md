# UI 设计基准

面向 Wyckoff 一切带样式的产出：桌面端界面、agent 生成的 HTML/Markdown 报告、图表、导出的 PDF。目标是让产出看起来像**交易研究台的作品，而不是营销落地页或通用 AI 模板**。

> 用户的个人偏好永远优先于下面的默认值。若用户在对话、记忆或设置里表达过口味（某个品牌色、某种字体、只要暗色），照做。下面是「用户没表态时」的强默认，不是推翻用户的许可。
>
> 这些是参考默认，不是牢笼。它们锚定质量、把你从偷懒的通用产出上带开，但不替代你的判断。当你对具体内容有明显更好、更自洽的选择，就用你的。唯三不可谈判的是**硬约束**（见下）。

## 硬约束（不可谈判）

1. **WCAG AA 对比**：正文 ≥ 4.5:1，大字/UI 元素 ≥ 3:1，对其所在背景。自定义配色必须验证。
2. **绿红只给盈亏**：`--up`/`--dn` 严格保留给涨跌、盈亏、beat/miss。**A 股惯例：红涨绿跌**（与美股相反，全项目统一）。绝不把绿红当装饰性分类色。
3. **主题变量 + 打印机制**：所有颜色走 `var(--role)`，双主题靠 `html.dark` 覆盖；动效必须尊重 `prefers-reduced-motion` 且在 `@media print` 下强制关闭 + `opacity:1`（否则入场动画导出成空白）。

## 基调：研究台，不是营销页

读者是投资者、分析师、组合经理，在读一份研究笔记。他们要的是**密集、可扫读、可信**的信息设计 —— 卖方研报、Bloomberg 终端、优质财经报纸的视觉语言。不是 SaaS 首屏。

- 信息密度优先于留白表演。研究读者期待高「每屏信噪比」。
- 克制优先于装饰。没有渐变首屏、没有浮在粉彩背景上的超大圆角卡、没有「立即开始」的能量。
- 数字是主角。表格、数据、图表撑起页面；散文是配角。
- 可信线索：标注来源、盖时间戳、标单位、精度一致。

## 避免 AI 通病

这些是通用 AI 界面的破绽，每条都给了替代做法。

| 反模式 | 为什么像 AI 垃圾 | 改用 |
|---|---|---|
| **到处 Inter / 纯系统字体** 当标题和正文 | AI 默认字体，零排版意图 | 承诺一个真实搭配（见排版）。标题用有个性的字体，正文用干净易读的 face。 |
| **紫/violet 渐变**，或任何渐变首屏 | 最被滥用的 AI 审美 | 一个扁平强调色，克制使用。背景是纸（浅）或墨（暗），不是渐变。 |
| **统一圆角卡片网格** — 一切都是 `border-radius:16px` + 阴影卡 | 营销模板脸，浪费纵向空间，压平层次 | 表格放表格数据，**发丝线**分隔区块，卡片只留给真正的 KPI 呼出。小圆角（4–8px）或无。 |
| **Emoji 当图标**（📈💰🚀） | 不严肃，打印会坏，渲染不一致 | 克制地用真实图标集（内联 SVG），或干脆只用干净的排版标签。多数研究界面不需要图标。 |
| **彩虹分类图** — 8 个饱和色无逻辑 | 像 Chart.js 默认盘，难读，无语义 | 克制的单色渐层调色板；绿红严格留给盈亏。分类色最多 3–4 个，且低饱和。 |
| **什么都居中** + 巨大顶边距 | 落地页构图，不利于扫读数据 | 左对齐阅读列，表格齐平，一致的基线网格。 |
| **占位符空壳** — 巨大空卡、Lorem 味填充 | 说明内容没被真正设计过 | 用真实数字和真实结论填充，容器尺寸贴合实际内容。 |

## 排版

**承诺一个有意的搭配** —— 一个标题声音 + 一个干净的正文 face。桌面端离线优先，用系统字体栈，不引 CDN；数字必须用等宽字形。

- **UI 声音**（导航、控件、chrome）：`--ui`，系统 sans 栈。
- **数字/代码**：`--mono`（JetBrains Mono → Menlo → ui-monospace 回退）。财务数字**必须** `font-variant-numeric: tabular-nums`，列才对齐、更新时不跳动。用 `.num` 工具类。
- **长文/报告标题**（可选）：`--serif`，给报告一点印刷研究感。

数字规则：数值列右对齐，同列小数精度一致（如价格都 2 位），单位只在表头标一次、不在每个 cell 重复。

## 配色

墨在纸上 + 单一强调色 + 两个语义财务色。一个强调色是纪律性的默认，只有当第二个色真正挣得其位（刻意的双色方案）才加，绝不当彩虹填充。

Wyckoff 现有调色板（已验证 AA，对比度为实测值）：

| 角色 | 浅色 | 暗色 | 对比度（对纸） | 备注 |
|---|---|---|---|---|
| 纸/页面 `--paper` | `#fffefc` | `#16181d` | — | 暖白读作印刷，纯白更刺眼 |
| 墨/正文 `--tx` | `#26251f` | `#e6e8ec` | 15.2 / 14.5 | 近黑，非纯黑 |
| 次要 `--tx2` | `#6f6d66` | `#a0a6b0` | 5.1 / 7.3 | 标签、说明、来源行 |
| 三级 `--tx3` | `#9b9891` | `#71777f` | 2.9 ⚠️ | 仅极弱提示，**不达 AA，勿用于正文** |
| 强调 `--clay` | `#d97757` | `#d97757` | 3.1 / 5.7 | 陶土色，标注语言，非 CTA 填充；仅大字/UI 达标 |
| 涨/盈 `--up` | `#e5484d` | — | 3.9 | 红（A股）；仅大字达标，正文级需加深 |
| 跌/亏 `--dn` | `#2f9e5f` | — | 3.4 | 绿（A股）；同上 |
| 发丝线 `--line` | `#e6e4de` | `#2b2f37` | — | 区块与表格行分隔，1px 或 0.5px |

规则：
- **绿红只给盈亏**，从不当装饰分类色。
- **暗色感知**：agent 生成的独立 HTML 报告，颜色写成 `var(--color-role, #字面回退)`，既跟随 app 主题又能独立/打印渲染。
- 分类调色板（真需要分类时）：从强调色派生 3–4 个低饱和渐层，而非满饱和色。超过 4 类 → 改用小倍数图或表格。

## 构图

- **一个阅读列**，左对齐，阅读密集布局 max-width ~`min(100%, 760px)`（数据密集视图可更宽）。居中的是列，不是列内文字。
- **发丝线优先于盒子**：区块标题上一条 1px 顶边框，比把一切裹进阴影卡更干净地承载层次。
- **KPI 行用真网格**：`grid-template-columns: repeat(auto-fit, minmax(160px, 1fr))`，一致 gap，基线对齐。
- **纵向节奏一致**：区块之间宽松，表格内部紧密。密集是数据的特性，留白用于分隔想法。
- **层次靠字重与字号，不靠颜色**。标题是更大更重，不是换个色。颜色留给语义（链接、盈亏）。
- **表格挣得其位**：斑马纹可选且要淡（2–3% tint）；表头下一条发丝线通常就够。数字右对齐，标签左对齐。

## 动效（克制）

研究文档里，动效是例外不是常态。

- 保持克制、有目的 —— 一次简短入场（区块交错淡入）就够。避免散乱的 hover 抖动、视差、无限循环。
- 图表可动画初次绘制，保持短。
- **尊重 reduced-motion，且绝不让动画阻塞打印**：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
@media print {
  *, *::before, *::after { animation: none !important; transition: none !important; opacity: 1 !important; }
}
```

（`@media print` 里的 `opacity:1 !important` 是防止入场动画元素导出成空白的关键，保留它。）

## 交付前检查清单

- [ ] 承诺了**一个**排版搭配（没有 Inter 当标题、没有纯系统字体）
- [ ] 用了真实字号阶梯，无临时字号
- [ ] 财务数字用 `tabular-nums`，数值列右对齐、精度一致
- [ ] **一个**强调色；绿红严格留给盈亏（A股红涨绿跌）
- [ ] 所有颜色走 `var(--role)` / `var(--role, #回退)`；正文对比度 ≥ 4.5:1 已验证
- [ ] 无紫渐变、无统一阴影卡网格、无 emoji 图标、无彩虹图
- [ ] 左对齐阅读列，发丝线优先于盒子，纵向节奏一致
- [ ] 动效（若有）尊重 reduced-motion，且在打印下强制关闭 + 恢复 opacity
- [ ] 读起来像研究台作品，不是营销页 —— 密集、可信、可扫读

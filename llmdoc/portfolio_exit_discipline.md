# 持仓退出纪律

- 先区分硬退出与酌情退出。有效止损已触发、确认破位、明确派发或账户级风控否决属于硬退出；题材降温、持有时间偏长、基本面吸引力下降但结构尚未破坏，属于酌情退出。
- 硬退出可以直接 `EXIT`，不得用案例注释拖延止损。酌情退出优先比较 `HOLD`、`TRIM` 和 `EXIT` 的机会成本。
- 对高辨识度、历史上反复受事件驱动且流动性充足的持仓，在没有硬退出证据时，可考虑 `TRIM` 后保留小额尾仓；尾仓仍需明确失效条件，不得演变为无限期死扛。
- 单日涨停不能反证此前所有风险判断，也不能自动证明“永远留尾仓”更优。只有可交易样本、回测和策略归因持续支持时，才修改确定性规则。
- 已清仓后出现涨停，不得为了弥补错过而追价；重新开仓仍须走候选准入、市场闸门和 OMS。
